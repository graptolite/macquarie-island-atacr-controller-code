Modifications applied to OBSTools after downloading v0.1.4 (from `pip install obstools`), followed by replacement from commit 3c2fef41fbdc44d2d280886bcddc978ad1a919db (https://github.com/nfsi-canada/OBStools/tree/master) of all files in the folders atacr/ and comply/, as well as scripts/atacr_clean_spectra.py and scripts/atacr_daily_spectra.py.

An overview of the changes are as follows:
- atacr/classes.py -> moved around some plotting code (which may not particularly necessary). Also ensure the daynoise unpacking doesn't introduce None in the middle of lists (e.g. when the correlation between channels 1-2 contains a bad window with None as the cross correlation for that window, it seems to cause the code to fail; the fix attempted here is to invalidate the entire day if this happens by setting all values to None). The same fix is applied to determining tilt parameters: where there's a window with missing tilt, the day's tilt parameters get invalidated otherwise the code appears to fail.
- atacr/plotting.py -> change x-limit on QC plot. Remove sta TF log-log plotting as it seems to give an error when the atacr controller code was run.
- scripts/atacr_transfer_functions.py -> declare the specpath variable unconditionally (as it seems to be required even if the conditional it depends on is turned off). The definition is the same as if the conditional were true. Add try...except block around some plotting code to prevent blocking errors when it's only plotting that fails.
- scripts/atacr_clean_spectra.py -> Limit number of threads used. Ignore tilt corrections for the full time range if any windows are missing horizontal components in order to avoid blocking error.
- scripts/atacr_daily_spectra.py -> Allow different numbers of channels recording throughout the recording period i.e. if only Z and P are recording for the first few days, and then all Z, P, 2, 1 record afterwards, treat the two recording periods independently (this is done using a for loop going over all timespans across which the same number of channels record - note however that this only looks at different channel counts rather than the exact channel contents*). Add try...except block when trying to get a day noise object to avoid blocking error (just don't write the day noise object if there's an issue). *This only affects MRO12, for which: 2020-10-27T00:00:00.000000Z 2021-06-03T00:00:00.000000Z (all channels) 2021-06-03T00:00:00.000000Z 2021-06-04T00:00:00.000000Z (hydrophone, vertical, horizontal 1, and for which no spectra was computed but also no accepted events were on that day so this didn't matter) 2021-06-04T00:00:00.000000Z 2021-11-26T00:00:00.000000Z (all channels). This modification is likely unsuitable for broader application.

Note: The LICENSE is copied from the underlying OBSTools package with line 3 modified to make this clear.
